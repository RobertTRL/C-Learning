Most frequently used features are #include, to include the contents of a file during compilation
and #define, to replace a token by an arbitrary number of characters

# File inclusion
Makes it easy to handle collections of #defines and declarations
Any source line in the form #include <filename> or #include "filename" 
is replaced by the contents of filename

# Macro substitution
A definition has the form
#define name replacement text

Names may be undefined using #undef

Formal parameters are not replaced within quoted strings. However, 
if a parameter name is preceded by a # in the replacement text, 
the combination will be expanded into a quoted string
with the parameter replaced by the actual argument

Each " is replaced by \" and each \ is replaced by \\ 

The preprocessor operator ## provides a way to concatenate actual arguments
during macro expression. If a parameter in the replacement text is adjacent to a
##, the parameter is replaced by the actual argument, the ## and the surrounding
white space are removed, and the argument is rescanned

# Conditional inclusion

The #if line evaluates a constant integer expression, if the expression is non-zero, 
subsequent lines until an #endif, #elif or #else are included
The expression defined(name) in an #if is 1 if the name has been defined, O otherwise

The #ifdef and #ifndef lines are specialized forms that test whether a name is defined
